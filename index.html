25 套动效 · 零依赖 · 无框架限制

给你的页面装上
会呼吸的光标

25 套鼠标光标动效，封装为零依赖 Web Component。原生 Canvas 绘制， 一行 import 即可使用，Vue / React / Next.js 与纯 HTML 通吃。 每套自带主题光标：原生光标被换成对应主题的箭头与围绕装饰。 现在就动一下鼠标 —— 页面上的光效就是它本身。

当前效果 雪花 <cursor-snow>
向下 ← 0 → 向上

每套动效自带主题光标（雪花冒寒气、火牙飘火星、闪电打电弧）， 并响应滚轮：向上滚在光标处喷出向上的效果，向下滚则向下， 每套的形态与运动都不同（雪花是六角雪片飘落、像素是方块走直线、闪电是折线电弧）。 移动触发拖尾，左键 / 右键长按可蓄力，松手释放。右键菜单已屏蔽， 按住 Shift 再点右键可唤出原生菜单。

Why

一层浮在页面上的光标层

它铺满视口、浮在内容之上，但 pointer-events: none —— 你的按钮、输入框、文字选择全部照常工作。这一点是整个设计的出发点。

➤

移动与蓄力 · 跟随光标

光标划过留下拖尾，生成速率跟着速度走 —— 慢移是稀疏几粒，快速划动是一条连续的带。 蓄力过程中仍可移动：粒子持续被吸向光标，吸附范围、旋转方向与最终爆发朝向都随之改变。

◉

点击与蓄力释放 · 两种力度

短按左键或右键，在光标处触发小规模爆发与一圈冲击波，把已有的拖尾粒子推开。 长按则进入蓄力，粒子越聚越密、核心逐渐发亮，松手时按蓄力程度释放 —— 左键与右键是两套不同的爆发形态。

⇅

滚轮与主题光标 · 都默认开启

滚轮由一枚带符号的势能值驱动：向上滚喷出向上的效果、向下滚则向下，上下滚互相抵消， 快速滚是一次持续喷发，停手后还会继续消耗一阵；25 套的形态与运动各不相同。 主题光标则把原生光标换成各主题的箭头与围绕装饰（雪花冒寒气、火牙飘火星）， 箭头保持标准轮廓不变形，只换配色 —— 不会让人找不到鼠标位置。两者都可单独关闭。

◎

零依赖 · 按需引入

纯原生 ESM + Custom Elements，不引入任何第三方库，也不需要打包器， 直接用 <script type="module"> 即可。每个动效独立文件、带 tree-shaking， 只用雪花就只引入雪花，不会把 25 套一起打包进去。

⇄

无框架限制 · 可多实例

Vue 模板里写 <cursor-snow>，React 里当自定义标签用，Next.js 里 dynamic(..., { ssr: false })。所有状态都在实例内部，同页放多个动效互不干扰， 粒子池按实例预分配，不用频繁 new 对象。

⛨

不干扰宿主

样式封在 Shadow DOM 内，监听器只读（不 preventDefault、不 stopPropagation）， 卸载时全部注销。移植自 25 个单文件原型，逐个做过差分验证：相同随机种子下逐帧比对绘制调用序列。

Get started

三行代码接入

引入动效模块（会自行注册自定义元素），然后在页面任意位置放一个标签。 主题光标默认开启，组件会自己注入隐藏原生光标的样式，宿主页面无需任何配置。 下面右侧的示例会随你选择的动效实时变化。

HTML
<!-- 引入后即注册 <cursor-snow> -->
<script type="module">
  import './src/effects/snow.js';
</script>

<!-- 放在 body 里即可，无需包裹容器 -->
<!-- 主题光标默认开启 -->
<cursor-snow></cursor-snow>
当前选中

      

    


    

      

        
 动态开关（JS）


const fx = document.querySelector('cursor-snow');

fx.cursorEnabled = false;   // 关：自绘光标消失，原生光标恢复
fx.cursorEnabled = true;    // 开

      

      

        
 动态开关（属性）


<!-- 属性变化实时生效，无需重新挂载 -->
<cursor-snow no-cursor></cursor-snow>

<!-- Vue -->
<cursor-snow :no-cursor="!cursorOn" />

      

    


    

      

        
 Vue 3


<script setup>
import 'cursorkit/src/effects/snow.js';
</script>
<template>
  <cursor-snow />
</template>

      

      

        
 Next.js


// 必须禁用 SSR：组件依赖 window
const Fx = dynamic(
  () => import('cursorkit/src/effects/snow.js'),
  { ssr: false }
);

<Fx />

◐

        
黑白两种底色

        
一键在纯黑与近白之间切换，方便在不同底色下看清效果。注意：这些动效用的是加法混合，深色底才是它们的主场；近白底上光标本身清楚，但拖尾与装饰会明显变淡。

      

      

        
▾

        
一个选择框切 25 套

        
完全自定义的下拉（不是原生 <select>），列出全部 25 套动效，点击即切换，方便逐个对比。

      

      

        
⬚

        
控件不挡鼠标轨迹

        
底部控件容器设了 pointer-events: none，只有按钮本身接收点击 —— 空白处划过不会中断拖尾。

      

      

        
↕

        
带势能指示

        
控件右侧有一条竖条显示滚轮势能：向上滚向上增长、向下滚向下增长，能直观看到上下滚如何互相抵消、停止滚动后如何继续消耗。
